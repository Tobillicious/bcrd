## Scope lock

This release records a **Riemannian, leading-large-spin, single-vertex** result
for coherent nondegenerate boundary data. It does not claim a
continuum/refinement limit, bulk-spin-sum control, Lorentzian or nonlinear
dynamics, or a derivation of four-dimensional general relativity.
