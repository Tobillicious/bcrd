# BCRD public archival release v0.1

**Release date:** 14 September 2026  
**Author:** Tobias Croydon-McRae  
**Archive:** Figshare  
**DOI:** https://doi.org/10.6084/m9.figshare.33716677

## Purpose

Version 0.1 is the first public archival priority disclosure for
Boundary-Complete Relational Dynamics (BCRD).

It freezes a reviewed programme state before completion of the current
phase-sensitive N=4 recoupling experiment.

The release is intended to provide a durable scientific timestamp for
results that had already survived the programme's author, hostile-review,
reconciliation, and provenance procedures at the stated cutoff.

## Scope

The release reports reviewed finite-system results concerning:

- locality and finite-range mediator architectures;
- native and engineered relational transport;
- predictive coarse records;
- finite common-CPTP-map compatibility;
- exact reconstructive closure after known-spin erasure;
- coarse process composition and causal-break testing;
- an operational adjacent-pair Racah / \(6j^2\) transition probability.

## Explicit nonclaims

Version 0.1 does **not** establish:

- a coherent physical Racah amplitude;
- a physical F-move;
- physical pentagon or Pachner composition;
- a Ponzano-Regge or Regge sector;
- continuum gravitational dynamics;
- quantum gravity.

The phase-sensitive N=4 discriminator described in the release was
prospectively frozen but its outcome was not part of v0.1.

## Relationship to this repository

Figshare is the stable archival object.

This GitHub repository is the curated public research record containing
papers, reviewed-result summaries, reproducibility materials, and
provenance associated with BCRD.

The active development archive remains separate and private.
