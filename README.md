# Boundary-Complete Relational Dynamics (BCRD)

**Boundary-Complete Relational Dynamics (BCRD)** is a research programme studying relational quantum dynamics, recoupling, and candidate quantum-geometric constructions.

This repository is the **curated public scientific record**. It contains publication manuscripts, reviewed results, reproducibility artifacts, release metadata, and frozen provenance associated with publicly reported claims. The active development archive is maintained separately and is not mirrored here.

## Research status and scope discipline

BCRD distinguishes carefully between finite common-map compatibility and predictive identification; reconstructive closure and genuinely lossy coarse-graining; mathematical maps and physically declared interventions; recoupling probabilities and coherent amplitudes; vertex-level semiclassical statements and continuum gravitational dynamics.

Negative results, withdrawals, and scope ceilings are retained as part of the scientific record.

**The September 2026 four-simplex release is not a claim that quantum gravity or full four-dimensional general relativity has been derived.**

## Public/private separation

Only frozen, publication-relevant material is promoted to this repository. Exploratory branches, preregistrations, scratch calculations, provider transcripts, and unfinished development lanes remain in the separate development archive.

The public release intentionally records **snapshots and provenance, not private development history**.
